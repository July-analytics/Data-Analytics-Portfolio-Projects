## Telco Customer Churn Analysis

 ## Project Objective
To analyze customer attrition (churn) patterns in a telecommunications company, identify key drivers behind customer churn, and provide data-driven recommendations to improve customer retention.

## Tools & Concepts Used
-	Tools: Python (Pandas, Matplotlib, Seaborn, Jupyter Notebook)
-	Concepts: Exploratory Data Analysis (EDA), Data Cleaning & Preprocessing, Customer Churn Rate Analysis, Revenue Risk Assessment

 ## Key Features & Visual Previews
-	Data Preprocessing: Handled missing values in ‘ TotalCharges’, converted data types (SeniorCitizen), and validated zero duplicates across 7,043 records.
-	Demographic & Usage EDA: Analyzed churn patterns across customer tenure, monthly charges and contract types.
-	Visual Analysis: Built distribution plots and bar charts to illustrate churn proportions and revenue impact.

## Key Business Insights & Recommendations
-	High Risk Segments: Customers with short tenure and higher monthly charges show significantly higher churn rates.
-	Actionable Strategy: Implement targeted retention offers and loyalty programs during the early months of customer onboarding to reduce early-stage churn.

## How to Run / Files
-  Clone this repository.
-  Ensure Python 3.x, pandas, matplotlib, and seaborn are installed.
-  Open and run `telco.ipynb` in Jupyter Notebook.
