## Employee Data Analytics & HR Insights (SQL)

## Project Objective
Analyze compensation structures, career mobility, and gender diversity across 300,000+ records in the MySQL employees database to provide actionable HR metrics.

## Tools & Concepts Used 
-	Database: MySQL 8.0
-	Advanced SQL: CTEs, Window Functions (DENSE_RANK, ROW_NUMBER), Multi-table JOIN, CASE WHEN
-	Objects: SQL Views, Parameterized Stored Procedures

## Key Insights
-	Salary Benchmarks: Identified top 5 earners per department and employees earning above department averages.
-	Pay Anomalies: Highlighted individual contributors earning more than their direct managers.
-	Career Growth & Retention:Tracked lifetime salary growth % and internal manager promotion rates.
-	Diversity:Measured department-level female-to-male ratios and gender pay gaps.

## How to Run
- Load MySQL employees sample database.
- Execute `Employee.sql` in MySQL Workbench
